# PayFlow premium visual refinement

## Goal
Elevate the existing PayFlow portal with more visual depth and premium finish while preserving all routes, layouts, navigation, terminology, permissions, data, and business behavior.

## Implementation

### 1. Strengthen the application frame
- Keep the deep navy sidebar and existing navigation groups.
- Refine sidebar depth, active states, header separation, workspace background, and content framing.
- Preserve current proportions and information density.

### 2. Upgrade shared presentation primitives
- Refine semantic color, border, surface, and shadow tokens without changing the approved navy, electric-blue, and teal palette.
- Improve panels, KPI cards, filters, fields, buttons, tabs, status indicators, empty states, and tables through clearer elevation and typography.
- Add restrained, fast interaction feedback with reduced-motion support.

### 3. Make operational data feel more premium
- Strengthen metric hierarchy and numeric readability.
- Reduce flat, repetitive card treatment through layered surfaces and more intentional section rhythm.
- Give the existing communication-to-payment funnel a more distinctive connected-flow treatment without changing stages, filters, links, or calculations.

### 4. Preserve branded entry experiences
- Keep the current Login, Activation, and customer payment structures and imagery.
- Align their controls and surfaces with the upgraded shared visual language without changing their flows.

## Technical details
- Concentrate changes in the global design tokens, application shell, and shared PayFlow UI primitives.
- Make only small page-level class adjustments where the shared primitives cannot provide the intended hierarchy.
- Do not add modules, dependencies, data, routes, or business logic.

## Validation
- Verify Login and logout, Dashboard, Clients, Accounts / Cases, Workflow, Communications, Rules, Human Review, Users, Integrations, Activation, and public payment routes.
- Confirm Admin and Supervisor visibility remains unchanged.
- Check desktop and mobile layout, interaction states, and browser console errors.
